# Лаба 4 «RAG-пайплайн» — 4 часа

Собери собственный RAG: от документов **по твоей сфере** до окошка, где нейросеть
отвечает на вопросы по этим документам.

## Что ты сделаешь

1. Зальёшь документы своей сферы в хранилище и заведёшь их реестр.
2. Нарежешь документы на куски, превратишь в векторы и сложишь в векторную БД.
3. Подключишь нейросеть и сравнишь два режима: **без RAG** (галлюцинирует) и **с RAG**
   (отвечает по документам). Замеришь качество поиска и заполнишь отчёт.

## Что понадобится

- Docker (Desktop на Mac/Windows, или `docker` + `docker compose` на Linux).
- ~8 ГБ свободной памяти.
- Интернет при первом запуске (качаются образы и модель).

## Старт

```bash
cd лаба-rag-4часа
docker compose up -d
docker compose exec py pip install -r /app/requirements.txt
```

Дальше иди по стадиям — в каждой папке есть свой `guide.md`, там **каждая команда
разобрана по шагам**:

| Стадия | Папка | Что внутри |
|---|---|---|
| 1. Документы и реестр | `01-загрузка-реестр/` | `guide.md`, `loader.py` |
| 2. Чанки и векторы | `02-чанки-эмбеддинги-векторы/` | `guide.md`, `chunk_embed.py` |
| 3. Вопрос → ответ | `03-вопрос-ответ-ui/` | `guide.md`, `retrieve.py`, `ask.py`, `evaluate.py`, `app.py` |

**Начинай с `01-загрузка-реестр/guide.md`** и иди по нему сверху вниз. В конце каждой
стадии есть чек-пойнт и раздел «если что-то пошло не так / как откатиться».

> **Windows?** Всё то же самое, только команды для PowerShell — в каждой папке рядом с
> `guide.md` лежит `guide-win.md`. Стек и пути внутри контейнера не меняются.

## Своя сфера — выбери вариант

Документы лежат в `documents/<сфера>/`:

| Вариант | Сфера | Папка |
|---|---|---|
| 1 | Нефтегаз | `documents/oil-gas/` |
| 2 | Металлургия | `documents/metallurgy/` |
| 3 | Химическая технология | `documents/chemical/` |
| 4 | Информатика и ВТ | `documents/cs/` (готовый демо-пример) |

Правило: один документ = один файл `NN-название.md`, где `NN` — номер от `01` (это и есть
`doc_id`). Хочешь добавить свои документы — правила в `documents/README.md`, а ссылки на
открытые источники — в `документы-источники.md`.

## Что сдать

Заполни **`отчёт-исследование.md`** — это твой результат лабы:

- таблица `recall@3` и `MRR` для трёх размеров чанка (200/500/1000);
- таблица «без RAG / с RAG» по 2–4 вопросам;
- вывод.

В конце файла есть **пример заполнения** — посмотри, как это выглядит.

## Состав репозитория

- `docker-compose.yml` — 4 контейнера (MinIO, Qdrant, Ollama, python).
- `requirements.txt` — pip-зависимости.
- `01-загрузка-реестр/`, `02-чанки-эмбеддинги-векторы/`, `03-вопрос-ответ-ui/` — стадии.
- `documents/` — документы 4 сфер.
- `документы-источники.md` — ссылки на открытые документы.
- `отчёт-исследование.md` — шаблон отчёта + пример.
