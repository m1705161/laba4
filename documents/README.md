# Документы (корпус для RAG)

Корпус раскладывается по сферам-вариантам. Каждая папка = один вариант лабы.

```
documents/
├── cs/           # Вариант 4 — Информатика и ВТ
├── oil-gas/      # Вариант 1 — Нефтегаз
├── metallurgy/   # Вариант 2 — Металлургия
└── chemical/     # Вариант 3 — Химическая технология
```

## Правила имён

- Один документ = один файл `NN-название.md` (например `01-lakehouse.md`).
- **`NN` в имени — это `doc_id`** (начинается с `01`). По нему стадия 2 метит чанки,
  а стадия 3 считает recall против `gold.csv`.
- Только текстовый слой: `.md`/`.txt`, без сканов-картинок (OCR — за рамками лабы).

## Как готовить документы (кратко)

1. Берём открытый PDF/HTML/статью (ссылки в `../документы-источники.md`).
2. Извлекаем текст (например `pymupdf` для PDF) → сохраняем `.md`.
3. Кладём в свою папку сферы и запускаем стадию 1 (`loader.py --folder documents/<сфера>`).

## Готовые корпуса по сферам

В каждой сфере уже лежат 5 документов и `gold.csv` (по одному вопросу на документ),
поэтому стадии 1–3 можно прогнать как есть, не собирая свой корпус. Для `cs/` это:
`01-lakehouse.md` (lakehouse), `02-medallion.md` (медальон), `03-scd2.md` (SCD Type 2),
`04-cdc-debezium.md` (CDC/Debezium), `05-benchmark.md` (бенчмарк).
